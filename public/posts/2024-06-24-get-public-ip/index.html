How to Find Your Public IP Address

Return to map

Different methods of obtaining the public IP address of a computer.

Using nslookup

nslookup myip.opendns.com. resolver1.opendns.com

Using curl

curl ifconfig.me

Using PowerShell

(Invoke-WebRequest -Uri "http://ifconfig.me/ip").Content

Using a browser

https://ip.me/
