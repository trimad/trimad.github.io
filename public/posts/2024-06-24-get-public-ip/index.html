How to Find Your Public IP Address

Published Jun 24, 2024 Updated Dec 12, 2025
Return to map
Categories Networking System Administration PowerShell
Tags #ip-address #shell #curl #nslookup

Different methods of obtaining the public IP address of a computer.

Using nslookup

nslookup myip.opendns.com. resolver1.opendns.com

Using curl

curl ifconfig.me

Using PowerShell

(Invoke-WebRequest -Uri "http://ifconfig.me/ip").Content

Using a browser

https://ip.me/
